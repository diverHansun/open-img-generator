# settings 模块 · data-model

## 1. Core Concepts

- **应用设置**：当前用户的非敏感持久化偏好；当前只有图片保留天数。
- **保留策略**：`null` 表示永不自动清理；正整数表示未收藏图片保留的天数。
- **本地数据汇总**：受管媒体、SQLite 数据库和本地日志占用的只读字节统计。
- **项目导出快照**：在导出开始时选定的一个 Project 的完成 Generation、Session 层级和可读媒体文件集合。

## 2. Lifecycle & Ownership

应用设置由设置 API 创建或更新；缺失设置文件解析为“永不自动清理”。保留策略由 storage cleanup 在每轮开始时读取。导出快照只在请求期间存在，下载结束后不保留新的应用数据。
